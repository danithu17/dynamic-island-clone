# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Aura Island team takes security and user privacy seriously. All clipboard data, scratchpad notes, and media playback metadata are processed 100% locally on your computer with zero telemetry.

If you discover a security vulnerability within Aura Island:

1. **Do not disclose the issue publicly** in GitHub issues or discussions.
2. Email the maintainers directly or use [GitHub Private Vulnerability Reporting](https://github.com/nabil24024004/Quick-Pill-Dynamic-Island-for-Windows/security/advisories/new).
3. Please include:
   - A description of the vulnerability.
   - Steps to reproduce or proof-of-concept script.
   - Impact assessment.

We strive to acknowledge all reports within 48 hours and provide a patch release as swiftly as possible.
